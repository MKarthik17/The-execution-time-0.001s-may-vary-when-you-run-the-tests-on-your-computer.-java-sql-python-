# Python Expense Tracker

## About the Project
This is a simple Python project that helps record expenses and calculate spending totals by category.

## Features
- Add expenses with unique IDs.
- Store expense categories in lowercase.
- Validate expense amounts and dates.
- Calculate total expenses by category.
- Test functionality using Python's unittest framework.

## Technologies Used
- Python
- unittest

## Project Structure
```text
Python-Expense-Tracker/
├── expense_tracker.py
└── tests/
    └── test_expense_tracker.py
```

## How to Run
1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Run the application code as required.

## How to Run Tests
Execute the following command from the project folder:

```bash
python -m unittest discover -s tests -v
```

## Learning Outcome
This project demonstrates Python functions, input validation, data handling, and unit testing.
